# 剪辑质检与返修单（cut-review）

## 1. 四类检查（按硬闸强度分层）

| 类别 | 检查项 | 强度 |
|---|---|---|
| 合法性 | 主轨连续、无重叠、总时长一致、片段时长区间、转场参数合法、枚举合法 | **硬**（不通过即阻断） |
| 可执行性 | 素材存在且可用、授权覆盖当前用途、源轨 in/out 在素材时长内、速度与帧率可行 | **硬**（不通过即阻断） |
| 连续性 | 越轴、视线匹配、景别跳变、光线与色温跳变、音量跳变、字幕安全区 | 咨询（给出建议，人决定） |
| 合规 | 价格口径、地域/品牌事实、平台规格、账号禁忌清单 | 硬（事实类） |

> 纪律（T-2026-0930-0015）：**审美口径不得写成硬闸**。"节奏不够快""调性不符""画面不够美"只能作为咨询项。

## 2. 连续性检查清单（咨询项，逐条给证据）

1. **越轴**：相邻两镜主体运动方向是否相反（左→右 接 右→左）；有则提示"可能越轴"，并给替代镜头或插入中性镜头的方案。
2. **视线匹配**：人物看向画面外时，下一镜应在对应方向给出被看对象（或用视线方向的空镜过渡）。
3. **景别跳变**：同机位相邻镜景别差异 <1 级（如中景接中近景）易产生"跳"感；建议改为硬切到不同角度或加大景别差。
4. **光线/色温**：相邻镜光线方向与色温差异过大时提示（连续场景优先保持同一光位与色温基准）。
5. **音量**：相邻段平均响度差 >6 dB 时提示加过渡或做响度对齐。
6. **安全区**：字幕与人脸、平台 UI 区域（标题带/点赞区）冲突时提示换位。

## 3. 返修单格式（必须可执行）

每条不合格项给出：

```
{ "segmentId": "seg-007", "field": "transitionIn.type", "current": "wipe",
  "problem": "从情绪段切入信息段使用划像，视觉上打断情绪", "action": "改为 cut，并把 0.4s 的停顿留给环境声",
  "severity": "advisory|hard", "evidence": "帧 00:01:12.400 前后 6 帧" }
```

- `action` 必须是"改成什么"，不是"建议优化"。
- `severity=hard` 只用于事实类；审美类一律 `advisory`。

## 4. 质检报告模板

```json
{
  "checks": [
    { "id": "timeline.continuous", "pass": true, "hard": true, "detail": "主轨 0–42.6s 连续" },
    { "id": "timeline.noOverlap", "pass": true, "hard": true, "detail": "同源片段最小间隔 2.1s" },
    { "id": "duration.target", "pass": true, "hard": true, "detail": "42.6s / 目标 40–45s" },
    { "id": "material.rights", "pass": true, "hard": true, "detail": "全部素材 cleared + timeline-source" },
    { "id": "continuity.eyeline", "pass": false, "hard": false, "detail": "seg-012 视线朝左，下一镜主体在左" }
  ],
  "fixes": [{ "segmentId": "seg-012", "field": "sourceIn", "action": "改用 shot:xxx（同场景右侧机位）", "severity": "advisory" }]
}
```

## 5. 自检清单

- [ ] 硬项（合法性/可执行性/事实合规）全部通过，否则不得进入合成
- [ ] 每条不合格都有"改哪一段、哪个字段、改成什么"
- [ ] 咨询项明确标注 `advisory`，不阻断交付
- [ ] 检查结论有证据（帧号/字段值/素材 id）
- [ ] 报告可直接进返修分诊（供剪辑制片排期）
